# Política de seguridad

Este repositorio es educativo y está destinado a comprobaciones locales o activos para los que el operador disponga de autorización expresa.

Para comunicar un defecto del código, aporta versión o commit, pasos mínimos, impacto observado, salida saneada y mitigación propuesta. No publiques credenciales, datos personales ni información sensible en incidencias públicas.

No utilices el contenido para acceder sin permiso, interrumpir servicios, recopilar datos ajenos o eludir controles. Esta política no concede autorización para probar sistemas de terceros.
