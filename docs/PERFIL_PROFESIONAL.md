# Perfil profesional

Perfil técnico orientado a la seguridad de sistemas, análisis defensivo, automatización con Python y documentación reproducible. Este portfolio reúne herramientas pequeñas y auditables, laboratorios controlados y procedimientos que explican los resultados, sus límites y las acciones recomendadas.

## Áreas de interés
- Seguridad defensiva y hardening.
- Inventario técnico y revisión de exposición.
- Seguridad web y cabeceras HTTP.
- Análisis inicial de registros.
- Automatización de tareas de auditoría.
- Laboratorios de redes y telemetría Wi-Fi.
- Diseño responsable de agentes de IA con herramientas limitadas.
- Respuesta a incidentes y documentación de hallazgos.
