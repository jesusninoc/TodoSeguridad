# Publicación en GitHub

## Antes de crear el repositorio
- [ ] Revisa `.env`, claves, tokens, certificados privados y logs reales.
- [ ] Ejecuta tests en entorno limpio.
- [ ] Revisa comandos, enlaces y ortografía.
- [ ] Añade resultados auténticos y capturas propias saneadas.
- [ ] Personaliza perfil y elimina afirmaciones no demostrables.

## Ajustes recomendados
Activa alertas de seguridad y Dependabot cuando estén disponibles, usa permisos mínimos en GitHub Actions y protege ramas si tu plan lo permite.

## Descripción sugerida
`Portfolio de ciberseguridad: herramientas Python defensivas, laboratorios reproducibles, hardening, análisis de logs y documentación técnica.`
