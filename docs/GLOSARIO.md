# Glosario

- Activo: sistema, servicio o dato que debe protegerse.
- Hardening: reducción de superficie de ataque mediante configuración.
- IOC: indicador útil para detectar actividad; requiere contexto.
- Triage: clasificación inicial para decidir prioridad.
- Falso positivo: alerta que no corresponde al problema buscado.
- Falso negativo: problema real que no se detecta.
- CVE: identificador público de una vulnerabilidad.
- CVSS: puntuación de severidad técnica; no sustituye el riesgo de negocio.
- SIEM: plataforma de recopilación y correlación de eventos.
- CSP: política del navegador para limitar recursos.
- HSTS: mecanismo para forzar HTTPS en navegadores compatibles.
- CSI: información del canal inalámbrico; su interpretación depende del hardware y entorno.
- STRIDE: método de modelado de amenazas.
- Mínimo privilegio: conceder solo los permisos necesarios.
