# Contribuir

- Explica el objetivo y el alcance del cambio.
- Usa datos sintéticos.
- Añade pruebas para reglas nuevas.
- Documenta falsos positivos y limitaciones.
- Evita dependencias innecesarias.
- No incluyas credenciales ni datos personales.
