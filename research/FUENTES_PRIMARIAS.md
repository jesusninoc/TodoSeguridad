# Fuentes primarias para estudiar

Consulta la versión vigente y registra fecha de consulta en tus informes.

- NIST Cybersecurity Framework: https://www.nist.gov/cyberframework
- NIST publicaciones: https://csrc.nist.gov/publications
- NIST National Vulnerability Database: https://nvd.nist.gov/
- MITRE ATT&CK: https://attack.mitre.org/
- OWASP Top 10: https://owasp.org/www-project-top-ten/
- OWASP Cheat Sheet Series: https://cheatsheetseries.owasp.org/
- CVSS: https://www.first.org/cvss/
- CIS Benchmarks: https://www.cisecurity.org/cis-benchmarks
- Python: https://docs.python.org/3/
- GitHub Code Security: https://docs.github.com/en/code-security
- ESP-IDF: https://docs.espressif.com/projects/esp-idf/

Cita la página concreta consultada y no atribuyas a una fuente conclusiones que no contiene.
